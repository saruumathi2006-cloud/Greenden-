# Greenden-tailwind


## 📖 About the Project

Greenden is a simple and responsive plant shop website built using **HTML**, **CSS**, and **Tailwind CSS**. The project is designed with a clean and modern user interface that works well on both desktop and mobile devices.

## 🚀 Features

* Responsive navigation bar
* Beautiful homepage layout
* Plant product section
* Customer reviews section
* Contact section
* Mobile-friendly design
* Clean and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* Tailwind CSS

## 📂 Project Structure

```
Greenden/
│── index.html
│── contact.html
│── product.html
│── output.css
│── images/
└── README.md
```

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Or clone the project using Git:

```bash
git clone https://github.com/your-username/greenden.git
```
